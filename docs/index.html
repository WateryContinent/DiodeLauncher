Diode News

Diode 2.0.0 Released

Diode now logs in with your Microsoft account, so you can finally play on online servers again!

The login screen is back to how it looked in the original launcher. Click Log in with Microsoft, enter the code it gives you at microsoft.com/link, and you're in. Diode never sees your password.

+ Added Microsoft account login
+ Restored the original login screen, including the saved accounts list
+ Saved accounts stay logged in and refresh automatically before you play
+ Accounts that don't own Java Edition can play the demo
* Clear messages for Xbox account problems, like child accounts or a missing Xbox profile
* A network hiccup no longer logs you out of a saved account
- Removed playing without an account (the offline name login)

Heads up: old offline names are removed when you update, so you'll need to log in with Microsoft the first time you open 2.0.0. Your worlds aren't affected.

Diode 1.2.0 Released

Diode now runs on macOS too, on both Apple Silicon and Intel Macs!

+ Added a macOS version (download the .dmg for your Mac from the releases page)
+ Crash reports can now be sent as a GitHub issue, or to Mojang's bug tracker
* Minecraft 1.18 and older now work on Apple Silicon Macs, using Rosetta
* Links on this page now open in your normal browser instead of inside the launcher
- Removed the old automatic crash reporting, which sent reports to a Mojang service that no longer exists

Mac heads up: Diode isn't signed by Apple yet, so macOS will block it the first time. Go to System Settings > Privacy & Security and click Open Anyway. Old Minecraft versions on Apple Silicon also need Rosetta; if they won't start, run softwareupdate --install-rosetta in Terminal.

Diode 1.1.0 Released

The first proper release is out! Diode now comes with a real installer and can keep itself up to date.

+ Added automatic launcher updates, checked when the launcher starts
+ Added a Launcher Settings tab to turn update checks on or off, check right away, or view all releases
+ Added a Windows installer with Java included, so there's nothing else to install
* Installed copies keep game data in %APPDATA%\.diode, so uninstalling won't take your worlds with it
* Fixed the broken login screen
* Fixed runtimes not downloading or working on Linux and macOS
* Your name now sticks around after clicking Switch User

Coming from 1.0.x? Grab 1.1.0 from the releases page once by hand. From here on, the launcher will let you know when there's something new.

The launcher lives again

After all these years, the old launcher is alive again once again.

A fair bit has changed behind the scenes to make it happier on modern computers while still keeping the wonderfully outdated look and feel of the original.

The goal: keep the launcher feeling old without requiring the computer running it to also be old.

+ Better support for modern Java versions
+ A much simpler offline login screen
+ Improved local multiplayer support
+ Simpler Per-profile memory settings
* Various fixes for ancient JVM arguments

The main reason I decided to create/start this project was because I was browsing on Internet Archive looking for stuff for my other project and I stumbled across the old launcher and curiousity got the better of me and I decided to give it a look.

I tried opening it and low and behold, it didn't work, duh. I decided to finagle around with it abit and managed to get to the main launcher screen and was hit with a wave of nostalgia, which birthed the project.

I also made this webpage to replace the old page that was in the launcher, which surprising was still working, you can find it here if you're curious https://mcupdate.tumblr.com/.
